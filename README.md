## Structure

Add one folder per week. Do not create them in advance — add each as you start it.

```
week02/
├── report.md      # the five-section report
├── code/          # everything you wrote
└── evidence/      # data files, photos, video
```

`model-spec.md` in the root is the exception: a **living document** you revise in place, week after week. Its history is read as well as its content.

---

## The weekly report template

Copy this into each `weekNN/report.md`. Same five sections, same order, every week.

```markdown
# Week N — <topic>

## 1. What we built
Two or three sentences. What exists now that did not exist last week?

## 2. Evidence
Your data. Numbers, a table, a short log extract, a photo.
Point to files in evidence/ rather than pasting large outputs here.

## 3. Question of the week
The reasoning question from that week's assignment guide. Answer it directly.

## 4. Model spec changes
What you changed in model-spec.md this week, and why. One or two lines.

## 5. Who did what
One line per team member.
```

Sections 2 and 3 carry most of the marks.
